# mos Dock

A customizable macOS-style bottom dock, independent from `mos-topbar` and
`samurai-dock`.

- Kind: **host adapter** (`host` in `plugin.json`)
- Floating glass dock at the bottom edge; click-through outside the dock
- Editable launchers: label, Nerd Font glyph and command
- Live appearance settings: icon size, spacing, opacity, magnification,
  magnification scale and labels
- Settings: Plugins -> mos Dock (`settings/MosDockPage.qml`)
- `defaultEnabled` is false
