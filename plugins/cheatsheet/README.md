# Keybind Cheatsheet

A searchable **cheat sheet of every active keybind** (core + plugin binds), read
live from `hyprctl binds`. Pairs with the `keybinds` editor plugin (which edits
them); this one only shows them.

- Kind: **panel** (`provides.panels.cheatsheet`, 760x640)
- UI: `ui/Cheatsheet.qml`
- Value producer: `scripts/cheatsheet.sh`
- Settings: Plugins → Cheatsheet

Open with `qs_manager.sh toggle cheatsheet`.
