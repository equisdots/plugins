# W11

An independent Windows 11-inspired bottom taskbar for equisdots. It ships its
own bar surface, start menu, app search and status area; it does not reuse the
core bar or open Rofi.

Features:

- Full-width taskbar or a compact centred dock.
- Windows 11 styling or palette-driven styling.
- Stylized X start button instead of a Windows logo.
- Smooth start menu with user information, app search, a six-column pinned
  app grid and power actions (lock, log out, restart, shut down).
- Independent clock, temperature and battery indicators.
- Lightweight Windows 11-style flyouts for battery, clock/calendar and quick
  settings; in compact mode they open centred above the taskbar.
- Configurable launcher glyphs, tinting and visibility.
- Start-menu app picker in settings: add or remove pinned applications without
  editing commands by hand.

Settings are stored in this plugin's own `settings.json` (`w11` scope).
